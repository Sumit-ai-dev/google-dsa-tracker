15 Core Patterns Reference

Identify which category a problem belongs to before writing code.

01
Sliding Window
Subarray/substring problems with max, min, sum, or frequency constraints (e.g., LC 3, LC 1004).
02
Two Pointers
Sorted array problems, pair-sums, in-place partitions, and duplicate removals (e.g., LC 15, LC 26).
03
Fast & Slow Pointers
Cycle detection, finding the middle of a linked list, or circular array traversal (e.g., LC 141, LC 876).
04
Binary Search
Sorted arrays, rotated arrays, or finding the optimal value in a monotonic answer space (e.g., LC 33, LC 875).
05
Prefix Sum
Range sum queries and continuous subarray sums equals K using a frequency hash map (e.g., LC 560).
06
Greedy Algorithms
When a locally optimal choice leads to a globally optimal outcome (e.g., LC 121, LC 55).
07
Backtracking
Recursion on decision trees: subsets, permutations, combinations, and pruning invalid branches (e.g., LC 78, LC 39).
08
1D Dynamic Programming
Linear state transitions where current solution depends on previous subproblems (e.g., LC 70, LC 198).
09
2D / Grid DP
Grid navigation paths, matrix path sums, and longest common subsequence (e.g., LC 62).
10
Bit Manipulation
XOR cancellation tricks (A ^ A = 0), bitmask state tracking, and checking set bits (e.g., LC 136).
11
Hashing & Frequency
O(1) lookups, counting anagram frequencies, and checking element existence (e.g., LC 1, LC 49, LC 128).
12

Python Standard Library Reference

Standard library modules and patterns for technical interviews.

1. Frequency Counting & Safe Dictionaries (collections)
from collections import Counter, defaultdict, deque

# Counter: Count element frequencies in O(N)
counts = Counter([1, 2, 2, 3, 3, 3])      # Counter({3: 3, 2: 2, 1: 1})
print(counts[999])                         # Returns 0 (No KeyError)

# defaultdict: Automatically initialize missing keys
graph = defaultdict(list)
graph["A"].append("B")                     # Key "A" is initialized automatically

freq_map = defaultdict(int)
freq_map["apple"] += 1
2. Double-Ended Queue for BFS (collections.deque)
# Note: In Python, list.pop(0) is O(N) due to element shifting.
# deque.popleft() is O(1).
queue = deque([root_node])

while queue:
    level_size = len(queue)
    for _ in range(level_size):
        node = queue.popleft()
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)
3. Min-Heap & Max-Heap (heapq)
import heapq

# Min-Heap (default in Python)
min_heap = []
heapq.heappush(min_heap, 10)
heapq.heappush(min_heap, 5)
smallest = heapq.heappop(min_heap)          # Returns 5 in O(log N)

# Max-Heap (invert values to simulate max-heap)
max_heap = []
heapq.heappush(max_heap, -10)
heapq.heappush(max_heap, -5)
largest = -heapq.heappop(max_heap)          # Returns 10
4. Binary Search Module (bisect)
import bisect

arr = [10, 20, 30, 40, 50]
# Find first index where 25 can be inserted to maintain order
idx = bisect.bisect_left(arr, 25)           # idx = 2
exists = (idx < len(arr) and arr[idx] == 25)
